# Security Policy

## Supported versions

The latest stable Kafkaesque release receives security fixes. Older releases
may require upgrading before a fix can be provided.

## Report a vulnerability

Email security reports privately to
[nikhil25803@gmail.com](mailto:nikhil25803@gmail.com). Do not open a public
issue, discussion, or pull request for a suspected vulnerability.

Include, when possible:

- The affected Kafkaesque version or commit.
- The affected component and deployment model.
- Reproduction steps or a minimal proof of concept.
- The expected impact and any known mitigations.

Do not send live credentials, access tokens, private keys, production data, or
other secrets. Use redacted examples.

Reports are reviewed and coordinated privately. No acknowledgement or
resolution time is guaranteed.

For deployment hardening and current limitations, read the
[runtime security guide](docs/security.md).
